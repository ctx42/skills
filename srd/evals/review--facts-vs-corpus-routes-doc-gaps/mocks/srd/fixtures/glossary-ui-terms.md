# UI Terms

## Build Board

The screen listing every open build order with its stages, assembly bay, and
freeze date.

## Launch Calendar

The screen showing booked launch slots day by day.

## Bay Map

The screen showing which build order occupies each assembly bay, Bay A to
Bay D.

## Mission Dashboard

The customer's screen for one customer mission, showing its payload, launch
slot, and status in the customer's time zone.

## Status Chip

A small colored label showing the state of a build order, customer mission, or
launch slot.

## Slot Picker

The control a customer uses to choose a launch slot inside the mission's launch
window.

## Telemetry Strip

A row of live telemetry channel values, one cell per channel, shown above a
chart.

## Replay Timeline

The time axis a user drags to replay the stored downlink frames of a flight or
hot-fire.
